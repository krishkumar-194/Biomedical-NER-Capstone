# Biomedical Named Entity Recognition (NER)

## NLP Capstone Project

### Project Overview
This project is a Biomedical Named Entity Recognition (NER) application developed using Natural Language Processing and Transformer-based models.

The application extracts and classifies biomedical entities from medical text.

### Objectives
- Extract biomedical entities from medical documents.
- Identify diseases, medications, symptoms, and other medical terms.
- Highlight extracted entities in the input text.
- Display entity categories and confidence scores.
- Provide an interactive web interface.

### Technologies Used
- Python
- NLP
- Transformers
- PyTorch
- Streamlit
- Pandas
- Scikit-learn

### Features
- Biomedical text input
- Text file upload
- Entity extraction
- Highlighted biomedical text
- Entity classification
- Confidence score display
- Entity statistics and visualization

### Installation

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project:

```bash
cd Domain_NER_Capstone
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```

5. Open the application:

```text
http://localhost:8501
```
